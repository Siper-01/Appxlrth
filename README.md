# Appxlrth

> 免费的逆向分析与应用保护工具箱 —— 由 S.E.Siper（小迁）开发维护

Appxlrth 是一款面向 Android 应用开发者与逆向学习者的**一体化工具集**，同时覆盖「逆向分析」与「应用加固保护」两条主线。它既可以帮助你分析、调试、脱壳 APK，也可以帮助你为自己的应用加上多层防护，抵御静态逆向、动态调试乃至当下流行的 AI 一键逆向。

简单理解：**应用破解 + 应用保护，一个工具全包。**

---

## 项目背景

最近 AI 逆向的能力越来越超前，许多软件即使加固得「五颜六色」，依然能被轻松还原。独立开发者耗费大量时间打磨的项目，成果却被一键扒取，心血付诸东流。

为此，Appxlrth 在持续迭代中引入了全新的 **Appxlrth V** 加固内核，将多项防护能力统一收纳，并专门针对 AI 逆向场景做了对抗设计，让普通开发者也能低成本地为自己的作品加上一层可靠的屏障。

## 功能总览

### 一、逆向分析功能

| 功能 | 说明 |
| --- | --- |
| **分析注入** | 辅助分析目标应用结构与注入逻辑 |
| **Dex 反编译** | 反编译 Dex 文件，查看与梳理代码逻辑 |
| **Xml 转 Java 代码** | 将布局 Xml 转换为 Java 代码，便于理解界面结构 |
| **iApp Decrypt** | 针对 iApp 项目的解密处理 |
| **Apk 在线脱壳** | 一键 Dump 加密保护的 Dex 文件，针对市面主流加固方案生效 |
| **Ai 辅助分析** | 借助 AI 能力辅助逆向分析流程 |

> **关于在线脱壳**：用于日常快速提取 Dex 做分析调试，不作为商业逆向用途。强防 Dump、做过反调试处理的安装包会直接脱壳失败，属于对抗层面的正常现象。若脱壳失败，可尝试网页版备用方案（56.al）。某数字加固暂不能脱出。

### 三、Appxlrth V —— 一键式保护工具

Appxlrth V 是全新的整合式加固内核，把旧版分散的防护功能合并统一，防护强度全面升级，省去分步配置的繁琐操作，普通开发者也能快速上手。

核心能力：

- **Appxlrth 加固** —— 一键综合加固
- **Dex Protect** —— Dex 加密混淆
- **So Protect** —— 底层 SO 专项防护
- **Dex2c** —— Dex 转 Native 代码
- **Vmp** —— 方法级虚拟化保护
- **防 AI 逆向** —— 对抗 AI 自动解析

文本替换、MD5 加密、多种进制转换、时间戳转换、MD5 解密（整活）等日常小工具。

聚合 MT（mt mcp）、NexusBridge（r2 mcp / unidbg mcp / logfox mcp）等多款逆向服务，打通工具之间的联动调试链路，拓展调试、模拟、日志分析等多功能场景。

## 功能详解

### 1. Appxlrth 加固

全新整合式一键加固内核，合并旧版分散防护功能，整体防护强度全面升级，适配日常软件防破解需求。省去分步配置的繁琐操作，普通开发者也可以快速上手。

### 2. DexProtect

针对 Dex 文件进行加密混淆，隐藏代码结构与核心逻辑，有效抵御静态逆向扒取源码。对类名、常量字符串做处理，提高阅读与梳理代码的成本。

### 3. SoProtect

底层 SO 专项防护，防止文件篡改、内存 Dump 抓取，封堵底层逆向调试路径。针对原生库增加基础完整性校验，降低简单篡改注入的风险。

### 4. 防 AI 逆向

专属代码污染防护，干扰各类 AI 模型解析，通过混入诱饵类、虚假常量，误导大模型输出错误代码，削弱 AI 逆向的效果。

> ⚠️ 注意：仅干扰 AI 自动解析，**无法完全阻挡人工深度逆向**，不要当做绝对安全的屏障。

### 5. VMP 2.0

抽取 Activity 方法到 Native 虚拟机执行，静态分析很难拿到真实逻辑。

> ⚠️ 注意：VMP 虚拟化会抽取业务方法至原生层执行，唯一缺点是抽完之后软件虽然能正常打开，但 UI 可能「神游去了」。

### 6. Mcp 服务合集

聚合 MT、NexusBridge 多款逆向服务，方便把本工具和其他逆向生态串联，满足不同场景下的调试分析工作。

### 7. Apk 在线脱壳

一键导出加密 Dex 文件，兼容多数加固包，脱壳失败可切换网页版 56.al 备用。仅供学习调试使用，请勿用于侵权破解他人软件。

## 使用须知与常见问题

**Q：为什么处理大文件很慢，甚至闪退？**

目前整套加固运算全部运行在**本地设备**，大体积 APK 处理时 CPU 与内存压力非常大，效率并不理想。文件体积越大，内存占用越高，低配置设备更容易出现异常。遇到闪退可以尝试拆分资源、减小原始安装包体积后再次操作。

**Q：会接入云端运算吗？**

作者正在寻找合适的服务器方案。后续如果可以接入云端运算，就能大幅缩短加固等待时间，同时改善闪退、内存溢出这类问题。

**Q：脱壳失败了怎么办？**

强防 Dump、做过反调试处理的安装包会直接脱壳失败，属于对抗层面的正常现象。可尝试网页版 56.al 备用。某数字加固暂不支持。

**Q：防 AI 逆向能保证绝对安全吗？**

不能。它仅干扰 AI 自动解析，无法完全阻挡人工深度逆向，请勿将其视为绝对安全的屏障。
